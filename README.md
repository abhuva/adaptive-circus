# Adaptive pedagogy through circus and the arts

How can an educator change an activity so a learner can engage with the challenge that matters to them? This project develops a practical method for answering that question. It grew out of inclusive circus practice and brings workshop observations into conversation with research in movement, education, and the arts.

Start with [the working method](docs/index.md) and [cases from practice](docs/cases.md). The [current inquiry](docs/inquiry.md) shows what we’re still exploring. The [research overview](docs/research/review.md) and [source catalogue](research/catalogue.md) provide the evidence behind the discussion.
