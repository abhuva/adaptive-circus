# Working agreement for adaptive pedagogy

Discussion can stay in conversation. The README introduces the project to a first-time reader. The current formulation of the method lives in [docs/index.md](docs/index.md).

## “Document this” triggers reconciliation

When Marc says **“document this”** (case-insensitive, including a request embedded in a longer message), carry out the whole sequence below in the same task.

1. **Identify the change.** State to yourself what is newly observed, proposed, supported, challenged, or decided. Preserve who made the observation and what remains uncertain.
2. **Find existing claims.** Read the method and the relevant case, inquiry, or evidence entry. Search the authored pages for the topic, synonyms, linked examples and earlier conclusions. Consult source records when the evidence is in question.
3. **Reconcile.** Decide whether the new material confirms, qualifies, contradicts, or replaces earlier wording. Check the scope of each claim before resolving an apparent conflict. Keep genuine disagreement and the observation that could distinguish the explanations.
4. **Edit the owning passage.** Update [the method](docs/index.md), [cases](docs/cases.md), [open inquiries](docs/inquiry.md), or [evidence](docs/evidence.md) in place. The [research synthesis](docs/research/review.md) explains the collection. Source transcriptions preserve what their authors wrote. Use Git history for superseded project wording.
5. **Check the consequences.** Revise affected summaries and cross-references. Close a resolved inquiry or name the decision still open. Update site navigation if a page moves or is added. Verify affected links and run the clean Zensical build described in [the site instructions](docs/reading.md).
6. **Report the result.** Tell Marc what changed in our understanding, which earlier claim was checked or revised, and what remains open. A confirmation of an existing claim can end with a source or example added to its existing entry.

Keep practitioner observations, participant accounts, published findings, and AI-proposed explanations distinguishable. Confirmed participation and a demonstrated change in capacity answer different questions.
